# 도카이도 53개 역 사진 수집 목록

이 폴더는 도카이도 여행 페이지용 사진을 고를 때 참고할 공개 이미지 출처 목록입니다. 사이트 코드나 배포 설정은 변경하지 않았습니다.

## 사진 사용 원칙
- 아래 링크는 Wikimedia Commons의 역별 이미지 검색 결과로 연결됩니다.
- 개별 사진을 사이트에 저장·배포하기 전에는 파일 페이지에서 저작자, 라이선스, 출처 표기 조건을 확인하세요. Commons에 있다는 이유만으로 모든 사진이 무조건 자유 이용 가능한 것은 아닙니다.
- 우타가와 히로시게의 도카이도 판화는 역사적 분위기를 보여주는 대안입니다. 현대 풍경 사진과 구분해 사용하세요.
- 현재 저장소에는 원본 이미지 바이너리를 아직 포함하지 않았습니다. 이 목록은 사진 후보를 찾고 라이선스를 검토하기 위한 인덱스입니다.
